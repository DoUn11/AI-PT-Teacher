# AI PT쌤 프런트엔드

학교 팀 프로젝트의 웹 화면이다. 별도 프레임워크나 빌드 도구 없이 HTML | CSS | JavaScript 모듈로 구성하며, 기존 FastAPI 백엔드 API를 사용한다.

## 로컬 실행

프런트엔드는 **5173**, 백엔드는 **8000** 포트를 사용한다. 포트는 로컬 개발 기본값이며 배포 주소를 의미하지 않는다.

먼저 저장소의 [백엔드 실행 안내](../backend/README.md)에 따라 백엔드를 실행한다. 이어 프런트엔드를 실행한다.

Windows PowerShell:

```powershell
cd frontend
python -m http.server 5173 --bind localhost
```

macOS | Linux:

```sh
cd frontend
python3 -m http.server 5173 --bind localhost
# 또는 Node.js와 Python 3가 설치되어 있다면
npm start
```

브라우저에서 [http://localhost:5173](http://localhost:5173)을 연다. 회원가입 후 로그인한다. 데모 계정이나 임의 운동 기록은 포함하지 않는다. 파일을 직접 여는 `file://` 방식은 지원하지 않는다.

### 백엔드 연결

- 기본 주소는 `src/api.js`의 `DEFAULT_BASE`인 `http://127.0.0.1:8000`이다. 로그인 화면에는 서버 주소 입력란이 없다.
- 다른 서버를 사용할 때는 `DEFAULT_BASE`를 변경하고 백엔드의 CORS 허용 출처를 확인한다. 현재 백엔드 기본 설정은 `http://localhost:5173`을 허용한다.
- `127.0.0.1`은 브라우저를 실행하는 기기 자신이다. 다른 기기나 배포 환경에서는 실제 서버 주소와 HTTPS 설정이 필요하다.
- 액세스 토큰은 `sessionStorage`에 저장한다. 새로고침 시 인증을 확인하며, 탭을 닫거나 토큰이 만료되면 다시 로그인해야 한다. 기존 백엔드의 토큰 유효기간은 기본 30분이다.

## 화면과 지원 범위

| 화면 | 내용 |
|---|---|
| 로그인 &#124; 회원가입 | 중앙 정렬 폼, 이메일과 비밀번호 입력, 회원가입 시 닉네임 입력 |
| 자세 분석 | 운동 선택, 웹캠 자세 분석, 반복 횟수와 피드백, 결과 저장 선택 |
| 운동 기록 | 종목별 누적 요약, 최근 기록, 반복별 점수와 피드백 |

- 오른쪽 위 버튼으로 라이트 | 다크를 전환한다. 테마는 브라우저에 저장한다.
- 시작은 초록색 재생 버튼, 종료는 빨간색 정지 버튼이다. 영상 위 상태는 정지 `Ⅱ`, 실행 `▶▶`로 표시한다.
- 카메라 아래 상태는 연결 중 | 모델 로딩 | 분석 중 | 저장 중처럼 짧게 표시한다. 오류 원인과 복구에 필요한 정보는 별도로 유지한다.
- 종목 드롭다운은 방향키 | Home | End | Enter | Escape로 조작할 수 있다.

## 기록의 범위

요약 수치는 백엔드의 종료된 세션 통계를 사용한다. 목록은 전체 최근 100건을 받은 뒤 선택 종목으로 필터링한다. 따라서 누적 통계와 화면의 최근 기록 건수는 다를 수 있다. 기록 행을 클릭하거나 키보드 Enter를 누르면 해당 세션의 상세 결과를 조회한다.

현재 날짜 선택과 기간 조회 UI는 없다. 백엔드에는 통계의 `since` 조건만 있고, 기록 목록의 날짜 범위 필터는 없다. 전체 기록 페이지 조회 및 날짜 필터는 추후 API 연동 작업이다.

## 검증

Node.js 20 이상에서 실행한다. 테스트용 npm 패키지 설치는 필요 없다.

```sh
cd frontend
npm test
```

자동 테스트 19개는 각도 계산, 판정, 분석기 설정 일치, 업로드 규약과 재시도를 확인한다.

UI는 로그인 | 회원가입 | 자세 분석 | 운동 기록을 320px | 390px | 768px | 1280px, 라이트 | 다크, 대표 150% 확대 조건에서 확인했다. 버튼 정렬, 드롭다운 너비와 키보드 조작, 표, 빈 기록 및 추가 예정 상태를 검수했다. 격리 브라우저의 모의 API 검사와 로컬 백엔드의 실제 계정 인증을 구분하여 확인했다.

실제 웹캠으로 운동을 완료하고 점수 정확도와 전체 저장 흐름을 확인하는 검증은 별도로 필요하다. UI 검수와 자동 테스트 통과가 실제 동작 분석 정확도 검증을 대신하지 않는다.

## 알려진 제약과 추후 작업

- 브라우저 카메라는 localhost 또는 HTTPS에서 사용한다. 브라우저의 카메라 권한 허용이 필요하다.
- MediaPipe 라이브러리와 모델은 외부 CDN에서 불러온다. 인터넷 연결이 필요하고 최초 실행에는 로딩 시간이 걸린다.
- 브라우저 분석은 MediaPipe, 별도 로컬 분석기는 YOLO를 사용한다. 기존 설정은 초기 임계값이며 모델별 보정과 실제 동작 검증이 필요하다.
- 분석 설정은 `analyzer`의 복사본이다. 설정 변경은 분석 담당자와 협의하고 일치 테스트를 통과해야 한다.
- 촬영 중 탭을 닫으면 세션이 진행 중으로 남을 수 있다. 정상 종료 버튼으로 마무리한다.
- 배포 주소, HTTPS와 CORS, 만료 토큰 처리, 추가 종목, 날짜 조회는 팀의 후속 작업이다. 개발 할 일은 UI에 상시 노출하지 않고 이 문서에서 관리한다.
- `.qa/`, 로컬 실행 환경, 테스트 DB, 계정 정보와 서버 로그는 Git에 포함하지 않는다. 배포 화면에 미리보기 경로나 샘플 데이터는 제공하지 않는다.

이번 변경은 `frontend/` 범위이며 백엔드 | 분석기 | 라즈베리파이 코드는 변경하지 않는다.
